# funcMap Test Viewer

Self-contained offline viewer for the pipeline run (20 papers through Step 620).

## Quick Start

1. Requirements: Python 3.9+ (Python 3.10+ recommended), standard library only.
   No Node.js, npm install, virtual environments, external APIs, or CDNs required.
2. Launch the viewer:
   ```bash
   python3 serve.py
   ```
3. Open the printed localhost URL in your browser (e.g. `http://127.0.0.1:8000`).
4. To stop the server, press `Ctrl+C`.

## Options

- Run on a custom or random port:
  ```bash
  python3 serve.py --port 8080
  python3 serve.py --port 0
  ```

## Interpretation and Evidence Limitation

The verdicts in this viewer were generated by the pipeline and are not human
accuracy judgments. Every Step 620 relation evidence reference and current
context passage resolves to the frozen Candidate B BioC export packaged with the
project. Relation sentences appear directly on each card. Full context passages
and their ordered source sentences are available in a collapsed evidence drawer.

## Manual confirmation

Each relationship has separate Triple and Context controls. Mark **Reviewed**
first, then mark **Correct** when applicable. A reviewed item with Correct left
unchecked is exported as `incorrect`. Progress is saved only in that browser and
device, so use **Download Review TSV** regularly and before changing browsers.
